# Lições Aprendidas

## Projeto 01

Durante este projeto aprendi:

- Instalar um servidor Ubuntu do zero.
- Navegar pela estrutura de diretórios do Linux.
- Administrar usuários e permissões.
- Gerenciar serviços utilizando systemd.
- Monitorar processos.
- Consultar logs do sistema.
- Instalar e remover pacotes com APT.
- Diagnosticar problemas básicos de rede.

Realizando testes práticos, e repetindo os procedimentos até compreender o funcionamento.
