# Projeto 01 - Ubuntu Server

## Objetivo

Implantar um servidor Ubuntu Server simulando um ambiente corporativo da empresa fictícia TechSolutions Ltda.

O projeto documenta desde a instalação do sistema operacional até a administração do servidor, preparando o ambiente para os próximos projetos da mentoria.

---

## Tecnologias

- Ubuntu Server 26.04 LTS
- OpenSSH Server
- Netplan
- systemd
- APT
- Bash
- VMware Workstation

---

## Competências Desenvolvidas

- Instalação do Ubuntu Server
- Estrutura do Sistema de Arquivos
- Administração de Usuários e Grupos
- Permissões de Arquivos
- Gerenciamento de Serviços (systemd)
- Monitoramento de Processos
- Análise de Logs
- Gerenciamento de Pacotes
- Configuração de Rede
- Configuração de IP Estático com Netplan
- Diagnóstico de Conectividade
- Documentação Técnica

---

## Funcionalidades Implementadas

- Instalação do Ubuntu Server
- Configuração inicial do sistema
- Criação e administração de usuários
- Gerenciamento de permissões
- Monitoramento de recursos do servidor
- Configuração da interface de rede
- Configuração de IP estático
- Configuração de DNS
- Testes de conectividade
- Preparação do servidor para acesso SSH

---

## Evidências Técnicas

- Ubuntu Server 26.04 LTS instalado
- Interface `ens33` configurada
- Endereço IP estático (`192.168.1.50/24`)
- Gateway configurado (`192.168.1.254`)
- DNS funcional
- Comunicação com a Internet validada
- Estrutura inicial documentada no GitHub
