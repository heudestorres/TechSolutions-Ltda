# TechSolutions Ltda.

Bem-vindo ao repositório da **TechSolutions Ltda.**, uma empresa fictícia criada para documentar projetos de Infraestrutura, Linux, Cloud e DevOps.

Este repositório faz parte da minha jornada de aprendizado e tem como objetivo simular um ambiente corporativo, documentando cada projeto desde o planejamento até a implementação.

---

# Objetivos

- Aprender Linux Server
- Administrar servidores Ubuntu
- Implantar serviços corporativos
- Automatizar tarefas com Bash
- Trabalhar com Docker
- Configurar Nginx
- Monitorar ambientes com Zabbix
- Criar dashboards com Grafana
- Estudar Microsoft Azure
- Produzir documentação técnica
